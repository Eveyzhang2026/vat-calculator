## 2. 税法知识点：增值税到底在算什么（本文硬核，约 600~800 字）

按"从一般到特殊"的顺序讲，每一节配一句"代码里怎么体现"。

### 2.1 两个纳税人身份
- 一般纳税人：能抵扣进项，税率 13% / 9% / 6%。
- 小规模纳税人：简易计税，征收率 3%（阶段性 1%）、不得抵扣进项。
- 代码映射：`industry_rates.json` 里 `taxpayer_type` 字段区分。

### 2.2 一般纳税人应纳税额
- 公式：应纳税额 = 销项税额 − 进项税额 − 其他抵扣
- 销项 = 销售额 × 税率；含税销售额需先价税分离：`销售额 = 含税 ÷ (1 + 税率)`
- 代码映射：`calculate_vat()` 中 `is_tax_inclusive` 分支做价税分离。

### 2.3 加计抵减（本文亮点政策）
- 适用：生产、生活性服务业等，按进项税额的 10% / 15% 加计抵减。
- 关键细节：以"进项税额"为基数；且**不超过抵减前的应纳税额**，抵减不完的**结转下期**。
- 代码映射：
  ```python
  add_deduction = input_tax * additional_deduction_rate
  applied_add = min(add_deduction, max(vat_before, 0))
  carry_add = add_deduction - applied_add
  ```

### 2.4 小规模免税起征点
- 月销售额 ≤ 10 万（或季 ≤ 30 万）免征增值税。
- 代码映射：`actual_sales <= exemption_threshold` 时 `vat_payable = 0`。

### 2.5 附加税费与综合税负率
- 附加税费 = 增值税应纳税额 ×（城建 + 教育费 + 地方教育费，默认 12%）。
- 综合税负率 =（增值税 + 附加税费）÷ 销售额，比单纯增值税税负率更全面。
- 代码映射：`surcharge = vat_payable * additional_tax_rate if vat_payable > 0 else 0`。

> 写作提示：每节末尾用"代码里一句话"收尾，体现"税法→建模"的转化，这是转型背书的核心证据。

### 5.1 怎么看「税负曲线图」（写给读者，可直接引用）

> 这张图是**情景分析曲线**，只在选「一般纳税人」时出现（小规模纳税人简易计税、无进项抵扣，不画）。

- **X 轴**：进项税额（元），从 0 扫到「销项税额上限」，分 20 档
- **左 Y 轴（紫线，带阴影）**：税负率(%)
- **右 Y 轴（橙线）**：应纳税额(元)
- 前提：**销售额和税率固定**，只让"进项税额"这一个变量变化

它在回答一个问题：**"这笔销售额不变时，进项发票拿多拿少，税负会怎么变？"**

以制造业为例（销售额 100 万、税率 13%、销项 13 万）：

1. **最左端（进项=0）**：应纳税额=13 万，税负率=13%（最高点，没抵扣）
2. **往右走（进项增加）**：两条线同步下降——进项越多，抵扣越多，税越少
3. **橙线穿过 0 的位置**：即"进项=销项"的**盈亏平衡点**，此时应纳税额=0、税负率=0
   - 例：进项达到 13 万时刚好抵平
4. **橙线继续变负**：进项 > 销项，形成**留抵税额**（下期接着抵）

**对读者的用处**：这是税务筹划的"可视化仪表盘"——想看"要把税负率压到 3% 得拿多少进项"，在紫线上找 3% 对应的 X 值即可；想看"进项不够会多交多少"，看橙线高度差。一句话：曲线斜率就是"充分取得专票"重要性的直观答案。

> 截图建议：用制造业 100 万销售额、进项从 0 扫到 13 万，这样"平衡点"一目了然。
